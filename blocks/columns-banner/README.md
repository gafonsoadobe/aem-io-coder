# columns-banner

Custom **columns** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

Layout is driven by cell order (no extra class needed):

- **Text cell first** (homepage): angled blue panel on the left, photo on the right.
- **Image cell first** (product pages, e.g. conta-corrente, seguros, emprestimo): photo on the left, dark-blue angled panel on the right with lime heading, text and a white trapezoid CTA. On mobile the panel stacks above the photo. The block gets `columns-banner-media-left`.
